Vice State Trophy Guide — an offline web app that guides and tracks all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy shows its official name, description and grade, plus a guide written in our own words that cites its sources. The checklist saves in the browser (localStorage) with export to a file and import back, filters by kind (story, missable, collectibles, activities, side quests, robberies, exploration, money, combat, misc, online), a spoiler setting that hides story trophies until earned, and a three-stage platinum roadmap (about 200 hours) with the one possibly missable trophy — Positive Mental Attitude, the Chapter 1 balcony meditation — flagged. Everything runs locally in the browser; the app makes no network request.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser.
